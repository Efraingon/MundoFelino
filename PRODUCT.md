# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Personas cuidadoras de gatos en Caracas que necesitan orientación práctica, contenidos de cuidado y una forma de encontrar atención veterinaria.

## Product Purpose

Mundo Felino reúne orientación educativa, una biblioteca de cuidados, un asistente conversacional y un directorio veterinario para ayudar a las familias a cuidar mejor a sus gatos.

## Positioning

Combina la consulta conversacional con contenido felino y datos de atención local en un mismo sitio pensado para Caracas.

## Operating Context

Las personas consultan desde el móvil o computador cuando tienen una duda sobre su gato, buscan información para aprender o necesitan ubicar una clínica antes de acudir.

## Capabilities and Constraints

- El chat ofrece orientación educativa; no reemplaza la evaluación veterinaria.
- La biblioteca, el directorio y el chat dependen de la API y de PostgreSQL locales.
- La aplicación usa React, Vite y una API .NET existente.

## Brand Commitments

- Nombre: Mundo Felino.
- Voz: cercana, clara y responsable.
- Referencia visual vinculante para este rediseño: El Gato Feliz, reinterpretada con fotografías propias y una paleta distinta.

## Evidence on Hand

## Product Principles

- Explicar con claridad y sin alarmismo.
- Dar prioridad a la consulta y a la seguridad del gato.
- Usar contenido y fotografías reales disponibles en el proyecto.
- Indicar cuándo se necesita ayuda veterinaria.

## Accessibility & Inclusion

- Navegación por teclado, foco visible y texto con contraste suficiente.
- Controles táctiles amplios en móvil.
